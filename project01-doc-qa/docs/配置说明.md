# 用户中心配置说明

> 配置中心:Nacos | 命名空间:prod | 分组:user-center
> 修改配置后通过配置中心热生效,无需重启;标注「需重启」的除外。所有数值类配置修改前必须知会平台组 oncall。

## 超时配置

| 配置项 | 默认值 | 可调范围 | 说明 |
|---|---|---|---|
| http.connect-timeout | 5s | 2s~10s | 连接外部服务(短信、风控)的握手超时 |
| http.read-timeout | 30s | 5s~300s | 等待外部服务响应的读超时,超过即失败 |

注意事项:读超时的**上限是 300 秒**,调大超时会拖长线程占用,除非和架构组确认过,否则不建议调到范围之外;两个超时均支持秒(s)/毫秒(ms)两种单位写法。

## Redis 连接池

| 配置项 | 默认值 | 说明 |
|---|---|---|
| redis.pool.max-active | 50 | 最大连接数,登录/鉴权链路共用 |
| redis.pool.max-idle | 20 | 最大空闲连接 |
| redis.pool.min-idle | 5 | 初始化连接数,需重启生效 |
| redis.pool.max-wait | 3s | 获取连接的最大等待时间,超时抛 JedisConnectionException |

注意事项:调大 `max-active` 前先确认 Redis 实例的 `maxclients` 余量,建议步长不超过 50 逐级调整并观察;调用方(网关、各业务服务)的连接数之和不能超过实例承载,具体实例规格相关参数由运维侧维护。

## 缓存策略

| 配置项 | 默认值 | 说明 |
|---|---|---|
| cache.user-info.ttl | 10 分钟 | 用户基本信息本地缓存时长 |
| cache.perm.ttl | 5 分钟 | 权限点缓存时长 |
| cache.login-fail.lock-threshold | 5 | 连续密码错误锁定阈值 |
| cache.login-fail.lock-duration | 30 分钟 | 锁定时长 |

注意事项:用户信息缓存 TTL 调大会导致改昵称/头像后展示延迟,客服类投诉优先检查此项;权限缓存和登录锁定阈值不建议在大促期间修改。

## 日志配置(需重启)

| 配置项 | 默认值 | 说明 |
|---|---|---|
| log.level | INFO | 可选 DEBUG/INFO/WARN;排查线上问题临时调 DEBUG 时,务必在 1 小时内调回 |
| log.retention-days | 15 | 日志保留天数,超过自动清理 |

注意事项:DEBUG 日志量约为 INFO 的 8 倍,磁盘水位超过 80% 时禁止开 DEBUG;日志中手机号、密码等敏感字段已脱敏输出,不要尝试关闭脱敏开关。
