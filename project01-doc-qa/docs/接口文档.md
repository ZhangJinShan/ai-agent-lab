# 用户中心服务接口文档

> 版本:v2.3 | 维护人:平台组 | 最后更新:2026-09-15
> 本文档描述用户中心(user-center)对外提供的 HTTP 接口。所有接口走网关统一前缀 `/api/v1`,响应为 JSON,字符编码 UTF-8。

## 通用约定

- 所有接口使用 HTTPS,请求头需携带 `X-Request-Id`(调用方生成,用于链路追踪;未携带时服务端自动生成并在响应头返回)。
- 认证方式:除登录接口外,其余接口均需在请求头携带 `Authorization: Bearer <accessToken>`。token 有效期 2 小时,过期返回 401。
- 错误响应统一格式:`{"code": "USER_xxx", "message": "..."}`,常见错误码见各接口说明。

## 登录接口

账号密码登录,换取访问令牌。

- **路径**:`POST /api/v1/users/login`
- **限流**:单 IP **100 次/分钟**,超过返回 429
- **是否需要 token**:否

请求参数:

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 用户名,长度 4~32 |
| password | string | 是 | 密码,需前端 RSA 加密后传输 |

响应示例:

```json
{"code": "USER_OK", "data": {"accessToken": "...", "expiresIn": 7200}}
```

注意事项:连续 5 次密码错误,账号锁定 30 分钟(错误码 `USER_LOCKED`)。

## 用户信息查询接口

按用户 ID 查询基本信息。

- **路径**:`GET /api/v1/users/{userId}`
- **限流**:单用户 **300 次/分钟**
- **是否需要 token**:是

路径参数:`userId`(long,用户 ID)。查询他人信息需要 `user:read` 权限点,否则返回 403。

响应字段:userId / nickname / avatar / registerTime。注意**不返回**手机号、邮箱等敏感字段;敏感信息查询走独立的内部接口,不对外开放。

## 修改密码接口

修改当前登录用户的密码。

- **路径**:`POST /api/v1/users/password`
- **限流**:单用户 **5 次/小时**
- **是否需要 token**:是

请求参数:

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| oldPassword | string | 是 | 旧密码,RSA 加密 |
| newPassword | string | 是 | 新密码,长度 8~20,必须含大小写字母和数字 |

注意事项:修改成功后,该用户的**所有 accessToken 立即失效**,需重新登录;新密码不能与最近 3 次历史密码重复(错误码 `USER_PWD_REPEAT`)。
